# Ukiyo-e Domain

浮世絵を画像から調べ、Twinfoldのデータに落とすときの知識。年代・寸法の数値は目安で、個別の作品は必ず所蔵館の記録で裏を取る。

## 1. 画像から読む手がかり

| 手がかり | どこにあるか | 何がわかるか |
|---|---|---|
| 落款（絵師の署名） | 画面の隅、題箋の近く。「〇〇画」「〇〇筆」 | 絵師。画号は時期で変わる（例: 初代豊国→国貞→三代豊国、北斎の画号変遷）。同じ号を複数代が使うので代数に注意 |
| 版元印 | 画面の余白。商標（山型など）＋屋号 | 版元。版元がわかると刊行時期と揃物の特定が絞れる |
| 改印（検閲印） | 版元印の近くの小さな丸印・楕円印 | 刊行年月の目安。下表 |
| 題・題箋・目録 | 画面上部の短冊、色紙形 | 揃物名、図題。揃物名は検索の最強の鍵 |
| 彫師・摺師の名 | 画面の余白（「彫〇〇」） | 主に幕末・明治。版の特定の補助 |
| 判型・縦横比 | 画像全体 | 判型の推定（実寸は画像から確定できない） |

### 改印の目安（刊行年代）

| 時期（目安） | 形 |
|---|---|
| 寛政2年頃〜天保13年頃（1790〜1842） | 「極」の丸印 |
| 天保14年頃〜弘化4年頃（1843〜1847） | 名主の単印 |
| 弘化4年頃〜嘉永6年頃（1847〜1853） | 名主の双印 |
| 嘉永6年頃〜安政5年頃（1853〜1858） | 干支＋月の印に名主印を伴う、または干支月の印のみ |
| 安政6年頃〜明治4年頃（1859〜1871） | 「改」と干支・月をまとめた印 |
| 明治9年頃以降 | 余白に「御届 明治〇年〇月〇日」と出版人の住所氏名 |

干支と月が読めれば年まで絞れる（例: 「巳」＋月 → 安政4年〈1857〉の可能性）。くずし字の読みは誤りやすいので、読みだけで結論を出さず所蔵館の記録と照合する。

### 判型と実寸（目安、トリミングで小さくなる）

| 判型 | 目安（縦×横） |
|---|---|
| 大判 | 約39×26.5cm |
| 中判 | 約26×19cm |
| 間判 | 約33×23cm |
| 細判 | 約33×15cm |
| 長判 | 約50×23cm |
| 柱絵 | 約70×12cm |
| 大短冊 | 約38×17cm |

続物（2枚続・3枚続）は大判を横に並べる。額装外寸はマットと額で本紙より各辺数cm〜10cm前後大きくなる。AR表示の `physical.dimensions` は額装外寸で持ち、`label` に「大判錦絵 額装 外寸 約◯×◯cm」のように本紙の判型と額装の区別を書く。

## 2. 状態評価の語彙

ディーラー・オークションのcondition reportで使う語。英語表記も併記する。

| 項目 | 語 | 意味 |
|---|---|---|
| 摺り | 初摺（early impression）／後摺（later impression）／後版・再版（later edition, re-cut）／複製（reproduction） | 初摺はぼかし・色版が揃い線が鋭い。後摺は版木の摩耗で線が太り、ぼかしや色が省略される。後版は版木を彫り直したもの |
| 色 | 色良し（fine color）／退色（fading）／変色（discoloration） | 紅・藍などの植物系色材は光で抜けやすい |
| 紙 | 虫損（wormholes）／しみ（stains, foxing）／折れ（creases, folds）／擦れ（rubbing）／薄れ（thinning）／破れ（tears） | |
| 補修 | 裏打ち（backed, lined）／補修（repairs）／補彩（retouched） | 裏打ちは価値に影響するので必ず記録 |
| 余白 | 余白あり（full margins）／トリミング（trimmed） | 版元印・改印が切れていると年代特定が難しくなる |

画像だけでは、初摺・後摺の確定、紙質、裏打ちの有無、補彩、退色した色と元の色の区別はできない。これらは「画像では判断不可」と書く。

## 3. 照合先

優先順。画像の特徴と揃物名・図題・絵師名で検索し、同じ図の所蔵品を探す。

1. ukiyo-e.org（複数館の横断検索） https://ukiyo-e.org/
2. 立命館大学ARC 浮世絵ポータルデータベース https://www.dh-jac.net/db/nishikie/
3. 東京国立博物館 ColBase https://colbase.nich.go.jp/
4. 大英博物館 https://www.britishmuseum.org/collection
5. ボストン美術館 MFA https://collections.mfa.org/
6. メトロポリタン美術館 https://www.metmuseum.org/art/collection
7. シカゴ美術館 https://www.artic.edu/collection
8. 国立国会図書館デジタルコレクション https://dl.ndl.go.jp/

一致の根拠は「構図が同じ」だけでは弱い。題・落款・版元印・改印のうち、どれが一致したかを書く。所蔵館の記録どうしで年代や版元が食い違う場合は両方を書く。

## 4. 画像の権利

- 江戸・明治の作品そのものは著作権が切れている。ただし撮影・スキャン画像の利用条件は提供元ごとに違う。
- Open Access（CC0など）を明示している館の画像を優先する（Met、シカゴ美術館など）。利用条件ページのURLと確認日を `display.rightsNote` に書く。
- 条件が不明な画像はrepoに入れない（CLAUDE.md §3）。
- 実物を保有していない画像は「Twinfoldが保有する実物の写真ではない」と書く。

## 5. Twinfold fixtureへの対応

| 調べた内容 | 入れる場所 | source |
|---|---|---|
| 所蔵館の記録で確認できた図題・絵師・揃物・版元・図柄の刊行年 | `rwa_verified` Eventの `metadata`（artist、era、seriesなど）と `title` | `offchain_evidence`（照合先URLを書く） |
| 画像からの推定、確度が中・低のもの | 同上の `metadata.note` に「推定」と明記 | `twinfold_interpretation` |
| 個体の状態 | `physical.condition` | 実物のcondition reportがあるときだけ `offchain_evidence`。ないときは「デモ用架空表記」と書く |
| 判型と額装外寸 | `physical.dimensions` | 本紙判型は目安、額装外寸は実測値がなければ推定と明記 |

「図柄の刊行年」と「この個体が摺られた時期」を分けて書く。後摺・後版なら図柄が1857年でも個体は後年。

## 6. 書いてはいけない表現

- 「真作」「本物を保証」「初摺と認定」「鑑定済み」。画像調査は鑑定ではなく調査メモ。
- blockchain／NFT／Passportが真正性や状態を保証するという書き方。
- 推定を事実として書くこと。確度（高／中／低）と根拠を必ず付ける。
